# ДЗ 56: Асинхронный цикл событий Node.js

Порядок выполнения process.nextTick, setImmediate и setTimeout(0) с логированием каждой операции.

## Структура

- `src/main.js` — решение задания
- `src/demo.js` — пример использования, запускается в консоли: `npm run demo`
- `server.js` и `public/` — веб-оболочка, которая показывает код и результат запуска

## Запуск оболочки

```bash
npm start
```

Откройте http://localhost:3000 и нажмите «Запустить демо». Порт можно изменить переменной `PORT`.
Зависимости устанавливать не нужно, нужен Node.js 18 или новее.
